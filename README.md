# F1 Race Strategy Simulator & Pit Stop Optimizer

A Formula 1 race strategy simulator built with Python, Pandas and Streamlit.

## Features

- Uses the 2025 F1 race calendar and circuit data
- Select a 2025 Grand Prix
- Choose starting position
- Choose car performance class
- Simulate dry and wet race conditions
- Simulate tyre degradation for:
  - C1 Hard
  - C2 Hard
  - C3 Medium
  - C4 Medium
  - C5 Soft
  - C6 Soft
  - Intermediate
- Compare different pit-stop strategies
- Automatically find the fastest simulated strategy
- Simulate different rain windows
- View lap-by-lap race performance
- Uses previous-lap pace smoothing

## Important

This is a simulation/portfolio project.

The circuit lap counts and 2025 tyre nominations are based on 2025 F1 data. Numerical tyre degradation, base race pace, pit-stop loss, car-class pace differences and other model parameters are simplified simulation assumptions rather than official F1 performance measurements.

Rain scenarios are representative deterministic scenarios, not predictions of actual weather.

## Technology

- Python
- Pandas
- Streamlit

## Run
